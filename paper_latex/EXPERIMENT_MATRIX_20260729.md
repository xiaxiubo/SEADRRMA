# TRACE 论文实验执行矩阵

## 1. 统一定义

### 1.1 算法缩写

| 缩写 | 算法 |
|---|---|
| TRACE | 最终训练完成的完整 TRACE |
| RMA | 无显式 Fast 惯量分支的单 TCN/RMA 基线 |
| PPO | 无历史适应模块的 PPO 基线 |
| PD+DOB | 调参后的 PD 加扰动观测器 |
| LQR | 基于标称模型设计的增广 LQR |
| RLS | 滑窗递推最小二乘惯量估计器 |
| EKF | 扩展卡尔曼惯量估计器，可选 |

### 1.2 统一记录指标

控制指标：

```text
位置 RMSE
最大绝对位置误差
切换后 0.5 s RMSE
恢复时间
力矩 RMS
RMS(Delta torque)
力矩饱和率
安全触发和实验终止次数
```

惯量估计指标：

```text
稳定段 RMSE
平均偏差和标准差
切换峰值误差
恢复时间
正负速度方向差
超出物理范围比例
```

实时指标：

```text
推理 mean/P95/P99/max
完整周期 mean/P95/P99/max
超过 5 ms 的周期数
WKC 异常次数
```

### 1.3 重复次数

- 仿真学习算法：推荐 `5` 个训练 seed，最低 `3` 个。
- 每个冻结模型：至少 `10` 个评价 seed。
- 实物主对比实验：每种算法重复 `10` 次。
- 实物辅助实验：每种算法和工况重复 `5` 次。
- 经典控制器在仿真中使用相同的噪声和初始条件 seed。

## 4. 新 TRACE 完成前可先运行的基线实验

按以下顺序执行：

1. HW-00：所有硬件零力矩和通信检查。
2. HW-01：PPO、RMA、PD+DOB、LQR 的固定惯量测试。
3. HW-03：RMA 和 PD+DOB 的正负恒速惯量切换。
4. HW-02：协议冻结后，提前采集 PPO、RMA、PD+DOB、LQR 的主切换数据。
5. SIM-02：在最终统一环境中重跑各基线固定惯量测试。
6. SIM-09：生成与硬件 `3/10 s` 时间轴一致的四种基线仿真数据。
7. 用已有日志开发和验证 RLS/EKF，不需要等待 TRACE。

前提：PPO/RMA 必须与新 TRACE 使用同一物理模型和训练随机化域。若不是，
这些旧模型只能用于预实验，不能进入最终论文比较。
